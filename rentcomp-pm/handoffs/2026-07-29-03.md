## Process changes made this session — all now standing

1. **Probe-first QA.** All 13 of 13c's defects were found *after* implementation;

   **adversarial rows about the input space** alongside AC rows. First applied to
   **F10-S1 and 9b** (dispatched this session) — check how those plans came back
   before extending it, they are the experiment.
2. **Reviewer dispatches carry the invocation rules.** I put them in all four
   dev/QA dispatches and omitted them from both reviewer dispatches, and
   `backend-reviewer` duly reported a count **44 short** — exactly WORKFLOW §2's
   documented under-collection of `scripts/tests/test_gate*.py`, the money-path
   tests. **The reviewer of the money path ran a suite without the money tests.**
3. **Reviewer dispatches demand adversarial probes and require each finding
   labelled by HOW it was verified** (probe / existing test / reading). Weight
   those three differently.
4. **Two reviewers only where they earn it** — money path and guard logic. On
   round 1, `backend-reviewer` on 13c was pure waste. Map/comp-row/bucket-table
   rows get one.
5. **Recording verified negatives measurably pays**: review time halved between
   rounds (42→21 min, 56→33 min) purely because retired findings were not
   re-examined. Keep doing it rigorously.
6. **Dispatch first, document after.** My latency is serial with everything.
   I was writing long queue entries *before* moving the next agent; that is
   backwards, and across ~16 handoffs it is hours.
7. **When two agents report suite counts on one SHA, diff the counts first.**
   A 44 in this repo is a signature that identifies the invocation.
