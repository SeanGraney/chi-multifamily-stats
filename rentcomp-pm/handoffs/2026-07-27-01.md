## Patterns worth carrying forward

**Session limits are the main risk to this project, and the PM cannot see them
coming.** There is no usage signal available — the first sign is a subagent
failing with a reset time. Three agents have died mid-story. Mitigations that
work: put "commit early and often" in every dispatch (proven: 3 commits vs 0),
and write a handoff at each story boundary. When an agent dies, **inspect the
tree read-only before deciding** — twice the work was complete and only needed
committing, and restarting would have thrown it away.

**Resume agents, don't respawn them.** `SendMessage` to a dead agent's id
restores its full context. Both recovered stories cost minutes instead of hours.

**The QA agents in this project are unusually good and should be trusted with
judgment, not just execution.** They have found: their own overclaiming test
(F0-S2 route test), their own test that passed without asserting its AC (the
writes-nothing test), a defect they caused in the dev's options (the list-vs-tuple
forcing), and a latent bug that would have bricked the tool (the ledger with no
month stamp). Give them room to flag rather than pin, and rule on their proposals
promptly — that loop is producing the project's best work.

**Ask devs to justify stubs, not just write them.** The F0-S2 stub discipline
(payload-level `stub_stage` warnings, a $1/sqft sentinel chosen *because* it is
unmistakable, a bidirectional version test) came from telling the dev that a stub
must not be mistakable for a real number later. Repeat that framing in stories
that stub.

**Two worktree races cost real time.** All git-touching subagent phases are
serialized — one agent owns the tree at a time. Do not relax this to buy
parallelism; it cost more than it saved both times. It also means F0-S1b cannot
run alongside F0-S4 even though the lanes differ.

**Never `git stash` without a pathspec.** I did it once to free the tree for a
docs commit and it swept the new handoff files in with the story WIP, which then
took several careful commands to untangle. `git stash push -- <paths>` scopes it.
Better still: commit on the branch you are on, then switch.
