**New WORKFLOW.md note added this session:** isolated worktrees share one
`.venv/` rooted at the main checkout — `pytest` inside a worktree needs

**Worktree-cleanup pattern discovered this session, worth repeating:** once
an agent's branch is merged to main, `git worktree remove <path>` + `git
branch -d <branch>` cleans up — but `git worktree list` shows `locked` on
a still-running agent's worktree; skip those, only clean up finished ones.
A QA agent's own ad-hoc verification branch (created because the canonical
`-qa` branch was checked out in a sibling worktree it couldn't re-checkout)
needed `-D` not `-d` since it was a separate merge-commit chain with
