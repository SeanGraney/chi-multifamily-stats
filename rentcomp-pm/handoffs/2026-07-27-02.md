## Two things session 1 got wrong that cost time — don't repeat

**Agent transcripts do NOT survive a PM session boundary.** Session 1's handoff
said to resume the F0-S4 QA agent by id; `SendMessage` returned "No transcript
found". Resume-don't-restart still holds *within* a session, but across sessions
you must spawn fresh with a full written brief. **So a handoff must carry enough
to re-dispatch from scratch, not just an agent id.** (Not purely a loss — the
re-spawned QA agent immediately found a defect the first pass had missed.)

**Worktree serialization did not actually hold** (incident #3, QUEUE.md). The dev
phase left `HEAD` on its own branch and QA inherited it. Every dispatch now states
the branch explicitly *and* tells the agent to verify `HEAD` at start rather than
trust what it inherits. Keep doing that.
